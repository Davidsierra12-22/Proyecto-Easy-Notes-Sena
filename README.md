# EasyNotes v2

Sistema de gestión educativa (matrículas, calificaciones, pagos, comunicación).

## Estructura

- `client/` — Frontend en React + Vite
- `server/` — Backend en Node.js + Express + MongoDB

## Requisitos

- Node.js >= 18
- MongoDB >= 6.0

## Instalación

Backend:

```bash
cd server
npm install
npm run dev
```

Frontend:

```bash
cd client
npm install
npm run dev
```
